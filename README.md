# 熊本大同青果 備品管理システム

社内備品を一元管理し、回収・保管・再利用をしやすくするためのWebシステムです。

## 目的
- 何が、どこに、誰のもとにあるかを把握する
- 使用中 / 未使用 / 修理中 / 廃棄を明確にする
- 回収した備品を次の実習生へ再利用する
- 不要な買い替え・二重購入を減らす
- 変更履歴を残す

## 利用方法

### 管理者
管理者アカウントでログインし、以下を利用します。
- ダッシュボード
- 備品一覧・検索
- 備品登録・編集
- 使用者・保管場所・部署・状態の管理
- 履歴
- 分析
- 管理設定
- QR発行・印刷

### QR利用（管理者専用）
備品のQRをスマートフォンで読み取ると、管理者用の備品詳細に進みます。
**未ログインの場合は管理者ログインが必要です。**
一般社員・実習生・匿名利用者には、QR経由でも備品情報・使用者情報・写真を公開しません。

管理者がログインした場合のみ、管理番号、備品名、使用・保管場所、
現在の使用者、状態、外観写真・型番写真、変更履歴を確認できます。
貸出・返却・引継ぎ・写真更新は専用の管理者操作から行います。
