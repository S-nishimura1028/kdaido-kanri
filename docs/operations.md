# 運用手順

## 基本サイクル
1. 備品を回収
2. 現物状態を確認
3. システム情報を更新
4. 未使用として保管、または修理中へ変更
5. 次の使用者へ再配置
6. 使用者を登録して使用中へ変更

## 最重要ルール
現物が動いたら、システムも更新する。

現物とデータが一致していることを最優先とする。

## ステータス
- 使用中: 現在使用者がいる
- 未使用: 再利用可能で使用者がいない
- 修理中: 故障・点検等で利用できない
- 廃棄: 利用終了

この4種類を基本とし、独自の状態を増やさない。

## 管理者の日常作業
- 新しい備品を登録
- 使用者・場所の変更
- 回収時の状態確認
- 写真更新
- 未使用品の確認
- 修理中品の確認
- 必要に応じて履歴確認
- QRラベル発行

## QR利用（管理者専用への切替後）
管理者が備品QRを読み取る。未ログインなら管理者ログインを行う。
ログイン後、その備品の詳細を直接確認・編集できる。
写真は管理者の専用写真更新操作で保存する。
公開QRでの写真更新と匿名閲覧は廃止する。

## QR印刷
使用用紙:
インクファクトリー LBLA4-WPG-27

印刷設定:
- A4
- 100%
- 実際のサイズ
- ページに合わせる: OFF

新しいシートを使用する。
メーカー推奨上、途中まで使用したシートの再給紙は基本的に避ける。

## 変更後の確認
システム改修後は最低限以下を確認する。
- 管理者ログイン
- 備品一覧
- 検索
- 状態絞り込み
- 備品詳細
- 登録
- 編集
- 履歴
- 分析
- QR表示
- QR未ログイン時はログイン画面だけ表示
- 匿名RPCと匿名写真更新を拒否
- 管理者QR経由の詳細表示と写真更新
- PC表示
- スマホ表示
