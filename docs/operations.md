# 運用手順

## 基本サイクル
1. 備品を回収
2. 現物状態を確認
3. システム情報を更新
4. 未使用として保管、または修理中へ変更
5. 次の使用者へ再配置
6. 使用者を登録して使用中へ変更

## 最重要ルール
現物が動いたら、システムも更新する。

現物とデータが一致していることを最優先とする。

## ステータス
- 使用中: 現在使用者がいる
- 未使用: 再利用可能で使用者がいない
- 修理中: 故障・点検等で利用できない
- 廃棄: 利用終了

この4種類を基本とし、独自の状態を増やさない。

## 管理者の日常作業
- 新しい備品を登録
- 使用者・場所の変更
- 回収時の状態確認
- 写真更新
- 未使用品の確認
- 修理中品の確認
- 必要に応じて履歴確認
- QRラベル発行

## QR利用
現場では備品のQRを読み取る。
ログイン不要。

QR画面で情報と現物が違う場合:
- 写真の違い → QR画面から写真更新可能
- 使用者・場所・状態などの違い → 管理者へ連絡し、管理画面で更新

## QR印刷
使用用紙:
インクファクトリー LBLA4-WPG-27

印刷設定:
- A4
- 100%
- 実際のサイズ
- ページに合わせる: OFF

新しいシートを使用する。
メーカー推奨上、途中まで使用したシートの再給紙は基本的に避ける。

## 変更後の確認
システム改修後は最低限以下を確認する。
- 管理者ログイン
- 備品一覧
- 検索
- 状態絞り込み
- 備品詳細
- 登録
- 編集
- 履歴
- 分析
- QR表示
- QR未ログイン閲覧
- QR写真更新
- PC表示
- スマホ表示
