# 運用手順

## 基本サイクル
1. 備品を回収
2. 現物状態を確認
3. システム情報を更新
4. 未使用として保管、または修理中へ変更
5. 次の使用者へ再配置
6. 使用者を登録して使用中へ変更

## 最重要ルール
現物が動いたら、システムも更新する。

現物とデータが一致していることを最優先とする。

## 備品情報の編集と廃棄
- 通常編集では備品名・メーカー・取得情報・保管場所・備考などを変更する。
- 使用者の割当を変更する場合は、現物確認を伴う貸出・返却・直接引継ぎの専用操作を利用する。
- ステータス・保管場所を変更する際は内容確認画面が出る。
- 新たに「廃棄」へ変更するときは、専用の廃棄理由（5文字以上）を入力する。理由は備考に追記し、編集履歴の「内容」にも表示する。
- 通信エラー時は保存済みの可能性がある。再実行前に備品一覧で最新内容を確認する。

## ステータス
- 使用中: 現在使用者がいる
- 未使用: 再利用可能で使用者がいない
- 修理中: 故障・点検等で利用できない
- 廃棄: 利用終了

この4種類を基本とし、独自の状態を増やさない。

## 管理者の日常作業
- 新しい備品を登録
- 使用者・場所の変更
- 回収時の状態確認
- 写真更新
- 未使用品の確認
- 修理中品の確認
- 必要に応じて履歴確認
- QRラベル発行

## QR利用（管理者専用への切替後）
管理者が備品QRを読み取る。未ログインなら管理者ログインを行う。
ログイン後、その備品の詳細を直接確認・編集できる。
写真は管理者の専用写真更新操作で保存する。
公開QRでの写真更新と匿名閲覧は廃止する。

## QR印刷
シート選択:
- 標準（屋内）: エーワン31373（A4・27面／62×31mm）。デフォルトはこちら。
- 屋外（自転車等）: エーワン31071（A4・24面／64×33.86mm）。屋外用フィルム。
- QRシールの印刷時に用紙を1（31373）／2（31071）から選択する。ページ単位で面数を切り替えるため、同一印刷ジョブに2種の用紙は混ぜない。
- 印刷開始位置は新品用紙なら1。2ページ目以降の開始位置は自動的に1になる。

保管場所・所属部署ごとの一括印刷：
- 管理者ログイン → 備品一覧 → **「保管場所・部署別に印刷」** を開く。
- 保管場所または所属部署を選ぶ。両方を指定すると、その両方に該当する備品だけが対象。
- 読み込み対象は、一覧の検索条件とは独立した全備品（削除・廃棄を除く）。部署は備品の「所属部署」であり、使用者個人の所属部署ではない。
- 候補件数と管理No.・備品名・保管場所・部署を確認する。管理No.未設定が含まれる場合は印刷不可。
- **「この条件でQR印刷」** → 用紙「1：31373」→ 新品は開始位置「1」。内容が印刷直前に変わった場合は中止して再確認。
- 27件を超えるなど複数ページになる場合は警告が出る。実機による複数ページ印刷は未検証のため、まず普通紙で検証する。
- **ラベルに印刷されるのは社名・QR・管理No.・備品名だけ。** 使用者、部屋番号、部署、保管場所をラベル自体には印字しない。

使用する複合機：RICOH MP C4504
- A4、縦、実際のサイズ／倍率100%、拡大縮小OFF、ブラウザ側の余白なし、ヘッダー・フッターOFF、片面
- 手差しトレイから新品のラベル用紙を給紙する
- ドライバー／複合機の用紙種類を「普通紙」のままにしない。ラベル紙／厚紙モードの具体的な設定は用紙メーカーとリコー保守担当の指示を優先する
- 特定用紙のMP C4504通紙保証は未取得。先に機器との相性確認をする
- 印字位置は普通紙で1〜2ページ試し刷りを行ってからラベル用紙に印刷する
- 切り欠き・剥がした跡がある使用済みラベルシートの再給紙は紙詰まりの恐れがあるため避ける
- 現物へ貼付後、スマホでQRを読み取り、管理者ログイン後に管理No.と備品詳細が一致することを確認する

## 変更後の確認
システム改修後は最低限以下を確認する。
- 管理者ログイン
- 備品一覧
- 検索
- 状態絞り込み
- 備品詳細
- 登録
- 編集
- 履歴
- 分析
- QR表示
- QR未ログイン時はログイン画面だけ表示
- 匿名RPCと匿名写真更新を拒否
- 管理者QR経由の詳細表示と写真更新
- PC表示
- スマホ表示

## 重複候補・QRシールの確認表
- 管理者ログイン → 備品一覧 → **「重複・シール確認」** を開く。
- 同じ使用者に、同じ名前の備品が2件以上登録されていないか一覧で確認。管理No.を開き、現物・保管場所・割当を照合する。
- 部署名や団体名が使用者に登録されている場合、同じ備品が複数あっても共同使用の可能性がある。**表示は重複「候補」であって自動判定ではない。**
- **「シール確認表をCSV出力」** は、登録されている廃棄以外の備品を一覧化し、印刷確認・貼付確認を「未確認」で出力する。既存の印刷・貼付履歴を復元する機能ではない。CSVで追記した記録はサイト内に保存されない。
- 登録ミスの取り消しと物理的な廃棄は異なる。備品の削除機能は追加していない。誤登録の場合も、担当者が現物・履歴を確認してから安全な是正方法を決定する。

## QRシール確認状況（管理者間で共有）
- 備品一覧 → **「QRシール状況」** を開くと、現在管理している備品（廃棄・管理対象外を除く）の確認状況が一覧できます。
- 状態は **未確認／印刷済み／貼付済み** の3段階。印刷していても過去分の記録がない場合は「未確認」です。未確認は未印刷の断定ではありません。
- QR印刷画面を開いたことだけでは印刷済みにしません。実際の印刷を確認したら「印刷済み」、現物の貼付まで確認できたら「貼付済み」を選び「保存」を押してください。
- 管理者による保存内容は本番データベースに反映され、他の管理者にも共有されます。保存直前に別の担当者が変更した場合はエラーを表示するので、再読込後に確認してください。
- 「QRシール状況」から現在の保存済み状態をCSVに出力できます。従来の「重複・シール確認」で出力するCSVは記入用の手作業確認表で、サイトへの反映はされません。
- 変更は通常の備品変更履歴にも残り、変更時刻と操作者IDを保存します。氏名や居住場所などをシールへ印字する機能とは関係ありません。
