# Supabase標準Magic Linkを使った同一ブラウザ内ログイン

## 背景と前提
- Supabase Freeプランの標準メールはログインリンク（Magic Link）を送る。
- 6桁コードをメールに記載するためのMagic Linkテンプレート編集は、現行の環境では独自SMTPまたはProプランが必要で、編集できない。
- Vercel Previewの保護画面を挟むと、メールリンクのリダイレクト後のログイン状態が保持されない場合があった。
- **ProプランやSMTPの契約・変更なしで動作させるため、メール内リンクのアドレスをコピーしてPreview画面に貼り付ける方式を導入した。**

## アプリ実装（このPRのPreviewのみ）
- ログイン画面でメールアドレスを入力し「ログイン用メールを送信」する。
- Supabase `signInWithOtp({email,options:{shouldCreateUser:false}})` を実行。未登録メールを自動登録しない。
- メール内の「Log In」ボタンを**クリックせず**、右クリックして「リンクのアドレスをコピー」する。
- アプリの「メール内のログインリンクを貼り付け」欄にコピーしたURLを貼る。
- URLをアプリのブラウザ内だけで検査し、Supabaseプロジェクトの正規ドメイン・`/auth/v1/verify`・`type=magiclink`・64桁の16進トークンに一致する場合のみ `verifyOtp({token_hash:token,type:'magiclink'})` を呼ぶ。
- 入力欄のURLを直ちに消去する。実行結果やトークンをコンソールやデータベースに記録しない。
- Supabaseのセッションが作成されても `profiles.role='admin'` かつ `is_active=true` のアカウントに限りアプリ画面へ入れる。テーブル・ストレージRLSは変更しない。
- 既存のメール＋パスワードログインは維持する。

## 実機確認
1. Vercelの最新プレビューデプロイに正規のVercel権限でアクセスする。
2. 登録済み管理者のメールを入力して、送信ボタンを**1回だけ**押す（429のレート制限が残っていれば解除まで待つ）。
3. 新しいメールのログインリンクを**開かず**、リンクURLをコピーする。
4. 元のプレビュー画面に戻り、URL入力欄に貼り付けて「貼り付けたリンクでログイン」を押す。
5. ダッシュボードと備品一覧が表示されることを確認する。QR付きURLで開いていた場合は該当備品の詳細が開くことを確認する。

## 注意
- ログインリンクはパスワードと同等の秘密情報。**ChatGPT・他人・スクリーンショットに貼らない**。貼るのは本人が開いている備品管理アプリ内の専用入力欄だけ。
- 一度クリックした／認証で使ったリンクを再利用できない。メール閲覧アプリがリンクを事前に開く場合もあるので、できる限りコピーだけ行う。
- ログイン状態はサイトのオリジンに紐づく。Previewの別のデプロイドメインや本番サイトでログイン状態は自動共有されない。
- 本PRはDraftのまま。Productionにはまだ適用しない。旧匿名RPC・公開写真バケットの停止は別のレビュー済み切替手順で行う。
- 同一ブラウザでのログインの実機テストは未完了。GitHub Actionsの模擬テストとVercelのREADYは実機ログイン成功を保証しない。
