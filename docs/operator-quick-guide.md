# 管理者向け かんたん操作ガイド（現場用）

**対象：熊本大同青果 備品管理システムの管理者のみ**  
本番サイト： https://kdaido-kanri.vercel.app  
現行コード（2026-10-28）の画面名・操作名に合わせて作成。印刷用のQRシール設定や検証専用アカウントの作成手順は、このガイドの対象外。

## 最初に覚えること

1. 管理者アカウントでログイン。備品情報・写真は、管理者以外に見せない。
2. **現物を動かしたら、必ずその備品のシステム情報も更新する。**
3. 貸出・返却・故障報告・場所変更は、備品詳細の **「QR クイック操作」** を使う。単なる備考の書き換えで代用しない。
4. 写真を撮るときは、現物の外観と型番・銘板を優先。**顔・氏名が分かる紙・私物などの個人情報は写さない。**
5. 保存に失敗したように見えても、通信状況によっては保存済みの場合がある。**連打せず、一覧・履歴を再読み込みしてから判断する。**

## やりたいことから選ぶ

| 目的 | 操作の流れ | 確認ポイント |
| --- | --- | --- |
| 備品を探す | **備品一覧** → 名前等で検索・状態で絞り込み → 対象を開く | 写真、備品名、現在の使用者、場所を照合 |
| 新しい備品を登録 | **備品一覧 → ＋ 新規登録** → 必須項目・保管場所・状態などを入力 → 保存 | 現物1台ずつ登録。管理No.は自動採番。登録後に備品詳細と履歴を確認 |
| 使用者を登録 | **管理 → 使用者マスタ → ＋ 使用者を登録** | 氏名・部署・居住場所などを確認。重複した人を作らない |
| 備品を貸し出す | 対象備品 → **「貸し出す」** → 使用者を選ぶ → 現物・相手・内容を確認 → 確定 | **未使用・使用者未割当**の備品だけ。使用中へ切り替わる |
| 備品を返却する | 対象備品 → **「返却を確認」** → 本体・付属品・破損を点検 → 再利用可／故障を選ぶ → 確定 | 回収が済んでから確定。未使用または修理中になり、使用者は解除される |
| 故障を報告 | 対象備品 → **「故障を報告」** → 具体的な故障内容を入力 → 確認して確定 | 故障内容は5文字以上。使用者がいる場合、勝手に解除しない |
| 保管場所を変える | 対象備品 → **「場所を変更」** → 移動先を選択 → 現物移動を確認 → 確定 | 使用者と状態はそのまま。廃棄済みは変更不可 |
| 使用者間で直接引き継ぐ | 対象備品 → **「使用者変更」** → 使用者マスタから次の人を選ぶ → 現物引継ぎを確認 | 使用中・修理中の割当済み備品に限定。新規貸出や返却には使わない |
| 写真を更新 | 対象備品の詳細 → **「写真を更新」** → 外観／ラベル写真を選ぶ → 保存 | 1枚10MB以下。既存写真との競合が出たら画面を開き直す |
| 備品を廃棄する | 対象備品 → **「情報を編集」** → 状態を「廃棄」に変更 → 廃棄理由を入力 → 確認・保存 | 廃棄理由は5文字以上。使用者割当や現物回収が済んでいるか確認 |
| 履歴を調べる | **履歴** または対象備品の詳細内の履歴 | 貸出・返却・場所変更など、操作と対象備品を照合 |
| 退去・退職に伴う回収 | **管理の退去チェック** → 使用者を選択 → 備品ごとに現物確認し返却・引継ぎ・回収不能を記録 → 対象を確認して利用終了 | 回収不能は調査記録を残し、見つかったら後から回収済みの処理を行う |

> ボタンは備品の状態によって無効・非表示になることがあります。まず備品の状態と使用者割当を確認してください。

## スマホでの確認

- 備品のQRをスマホで読むと、管理者ログインを経由してその備品の詳細へ進む。
- 画面上で**管理No.、備品名、使用・保管場所、使用者**を現物と照合する。
- 未ログイン・非管理者には備品情報を公開しない。QRを第三者へ見せても閲覧権限は付与されない。
- QRが読めないときは、備品一覧の検索・絞り込みで探す。

## 困ったとき

| 症状 | まず行うこと |
| --- | --- |
| 「貸し出す」が押せない／出てこない | 備品が**未使用**で使用者未割当か確認。使用者候補がなければ使用者マスタに登録 |
| 「返却を確認」が押せない | 使用者が割り当てられ、状態が**使用中または修理中**か確認 |
| 保存で通信エラー | **同じ操作を連打しない**。一覧を再読込し、備品詳細・履歴に反映済みか確認 |
| 写真更新で競合エラー | 別管理者が先に更新した可能性。開き直して現在の写真を確認 |
| QRから詳細が開けない | 正しい本番URLか確認し、管理者でログインし直す。一般アカウントでは閲覧不可 |
| 登録内容が実物と違う | 現物を再確認し、状態・場所・使用者の変更は適切な専用操作で記録 |
| 備品が見つからない | 使用者・設置場所・履歴を確認し、確認できないまま「返却済み」にしない |

## 管理者の業務チェック

- **日々**：貸出・回収・移動のあと、対象備品の状態と使用者を更新。
- **週単位**：未使用・修理中・回収不能の一覧を確認。長期未対応の理由を記録。
- **退去時**：1件ずつ現物確認し、必要な付属品・破損・回収場所を記録。
- **運用上の原則**：実際の社員・実習生の個人情報を、操作確認のためにコピーしたりダミー扱いしない。

詳細ルール：[運用手順](operations.md) ／ [セキュリティ](security.md) ／ [会社への引継ぎ](handover.md)。

**このガイドは本番データを操作せずにコードを照合して作成したものです。各画面の現物操作による最終確認は別途必要です。**
